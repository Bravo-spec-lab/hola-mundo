# Ejercicios en Turbo Pascal

Repositorio con ejercicios básicos desarrollados en Turbo Pascal.

## Archivos

- `01_hola_mundo.pas`: muestra el mensaje `Hola Mundo`.
- `02_operaciones.pas`: solicita dos números y calcula suma, resta, multiplicación y división.
- `03_procedures.pas`: realiza las operaciones usando varios `procedure`.

## Consideraciones

El programa de operaciones valida la división entre cero para evitar errores durante la ejecución.
